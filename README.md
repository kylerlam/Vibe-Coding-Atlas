## 🧠 策展理念 (The Philosophy)

**Vibe Coding** 不僅僅是生成代碼，它是一種關於「品味」與「溝通」的藝術：

1. **意圖傳達：** 如何精準地向 AI 描述心中那種「說不清的感覺」。
2. **審美篩選：** 在無數可能的生成結果中，鎖定最具靈魂的那一個。
3. **極速打磨：** 利用 AI 的生產力，將創意到落地的時間縮短至分鐘級。
